# 历史成分与复权数据缺口（2026-09-30 只读核查）

本核查不写数据库；以下为本机 AKTools `http://127.0.0.1:8090/api/public/` 的实测响应。结果只说明该本地服务当前可用性，不代表其他数据供应商没有这些数据。

| 需求 | 实测接口与结果 | 对生产验证的影响 |
| --- | --- | --- |
| 退市日期 | `stock_info_sh_delist`：HTTP 200、159 行，字段含公司代码、上市日期、暂停上市日期；`stock_info_sz_delist`：HTTP 200、208 行，字段含证券代码、上市日期、终止上市日期。按主板代码和 2023-01-01 至 2026-09-29 退市日期粗筛约 119 行，存在重复，需去重和核验停牌日与真正终止日。 | 可初步恢复退市名单，但清单不足以形成可回测样本。 |
| 退市股历史行情 | 对 `600070`、`600077`、`600083`、`600112`、`600122` 请求 `stock_zh_a_daily` 均 HTTP 500。`stock_zh_a_hist` 对退市码 `600070` 与正常码 `600519` 均 HTTP 500。 | 当前接口无法补全幸存者偏差；需更换历史行情源并验证退市前最后可交易日。 |
| 每日 ST 状态 | `stock_zh_a_st_em` 无参和带 `date=20260101` 两种请求均 HTTP 500。本地 `stock_base.status` 是现状快照，`AkToolsMarketDataProvider.fetchStockList()` 对返回名单统一写 `active`。 | 无法确认任一历史交易日是否 ST，5% 涨跌停和历史选股资格可能错判。需可追溯的逐日名称/状态源。 |
| 复权时点 | `stock_zh_a_daily` 对 `600519` 的 `adjust=''` 和 `adjust='qfq'` 都 HTTP 200，分别提供未复权与前复权 OHLC。贵州茅台 2024-01-02 的前复权收盘价在 `end_date=20240131`、`20250131`、`20260131`、`20260929` 的查询中均为 1531.22。 | 同值并不能证明所有历史 qfq 值在 T 当日已知。当前 CSV 没有调整因子快照；生产回测应使用未复权价加当时公司行为记录，或保留逐日复权因子版本。 |

本次 `mainboard_liquid_stable_v1` 资格仅用 T 日及以前的行情；它不能修复来源于 2026-09-30 当前上市且当前非 ST 快照的幸存者偏差。规则出现 65% 的观察准确率后，仍须在逐日历史成分、历史 ST 状态和真实可得价格口径下复核，且用未参与搜索的新股票与未来时段验证。
