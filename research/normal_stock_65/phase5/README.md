# 历史时点主板样本与固定看涨规则压力测试

本阶段修正第四阶段历史 80 股样本的未来生存状态筛选问题。先在已保存的 BaoStock 历史成员快照中冻结 100 只主板股，再采集行情；股票抽样不检查未来是否退市、股价、收益或规则标签。这里只做**事前固定**规则组的一次压力测试，不在这批股票上优化阈值。

## 冻结方式与数据

- 历史成员来源为第四阶段 `query_all_stock(day)` 在 **2019-01-02**、**2023-01-03** 保存的 `historical_snapshot_membership.csv`，SHA-256 `dcb2dcf5c96a2a5a2789f738b334434b14701d6b2c181a6f0ea389a83bcc848b`。BaoStock 成员信息未获得交易所独立核对。

- BaoStock 逐股查询自快照日至 **2026-09-29** 的未复权日线、逐日 `tradestatus` 和 `isST`。首轮在第 80 只后会话失效，后 20 只返回 `10001001 用户未登录`；续采前检查冻结名单和首轮 CSV SHA，续采后重构并核对原有 80 股行情及覆盖文件 SHA。原始和最终 SHA 记录在 `pit_baostock_manifest.json` 的 `retry_history` 与 `sha256`。最终 **100/100** 股票有数据，**134,752** 行，**0** 未解决采集错误；最终原始行情 SHA-256 为 `789d5137b853e864b42c2992bfdb276a1e4b3eb2801296b0069490d77e358c98`。
- `audit_pit_coverage.py` 重演冻结抽样、检查所有输入和输出 SHA 及逐股日期唯一性：正常交易有效价格行 **134,291**；OHLC 区间违规 **0**、成交额除成交量超出日内高低区间 **0**。按既有 `mainboard_liquid_stable_v1`、逐日非 ST 条件，合格 **39,782** 股票日、**96** 只股票。年度覆盖见 `pit_coverage.json`。

## 一次固定规则组测试

条件来自第四阶段训练期（第二阶段开发 200 股、2020–2023）**排名第一**的看涨投票组，固定为以下 3 条至少命中 2 条：

1. T 日近 5 个交易日跌幅至少 10%；
2. T 日开盘较前收高至少 2%；
3. T 日沪深 300 收盘位于当日高低区间下 20%。

预测定义：T 日收盘后发信号，T+1 市场开盘至 T+2 市场开盘**严格上涨**算正确；缺失或停牌开盘计错。资格为 T 日已知的正常主板、非 ST、`risk_status=normal`。同一股票重叠持有时只保留较早信号；看涨方向正确率与扣往返 0.30% 成本的做多净胜率分开。`pit_fixed_vote_stress.json` 保存完整结果，脚本校验源规则组仍为预定的三条件 2/3 投票。

## 复现

在仓库根目录执行。若仅核验已有数据与固定规则测试，不需要 BaoStock：

```bash
PYTHONPATH=/tmp/stock_data_quality_baostock python3 -m research.normal_stock_65.phase5.audit_pit_coverage
python3 -m research.normal_stock_65.phase5.stress_frozen_vote
```

首次采集需在冻结文件不存在时依序执行 `collect_pit_sample.py freeze`、`fetch`；现有冻结文件故意禁止重建覆盖。临时 `PYTHONPATH` 提供 `baostock==0.9.4`，项目依赖未变。采集脚本支持在 source 会话失效且首轮输出 SHA 校验通过后执行 `resume`；这次续采 CSV 写完、更新 manifest 前遇到类型错误，故 `finalize-interrupted-resume` 在无网络情况下重建首轮 CSV 并检查旧 SHA 后完成 manifest。所有原始名单、行情及过程哈希留存。

本样本较第四阶段 80 股减少了明确的未来退市排除偏差，但它是 100 股样本，仍有历史成员源可靠性、公司行动、同一市场日期、抽样和交易执行限制。规则只应视作辅助决策研究结果，当前不能用于宣称保证收益或生产级 65% 看涨命中率。封存 100 股的行情和标签未读取。
