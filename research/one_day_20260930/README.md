# 一日持有规则研究行情样本

本目录仅用于隔离研究，不写入生产行情库。运行 `python3 collect_ashare_daily.py` 可从本机 AKTools 重建 `ashare_daily_qfq.csv`、`universe.csv` 和 `manifest.json`。当前冻结样本是 2026-09-30 的 166 只 A 股，含 2023-01-03 至 2026-09-29 的 142765 条前复权日线，数据哈希见 `manifest.json`。量化验证运行期间不要重建或覆盖 CSV。

## 抽样与质量

- 股票池来自 `stock_info_a_code_name` 的当前股票快照，排除当前名称含 `ST`/`退` 的股票；用固定随机种子 `20260930` 对深市主板、沪市主板、创业板、科创板、北交所分层抽样，另纳入本地库中已有长序列的 7 只股票。完整名单和每只股票起止日期见 `universe.csv`。
- `stock_zh_a_daily` 提供前复权 OHLCV。`pre_close` 是同只股票前一个有效行情行的 `close`，仅供数据核查；执行回测应依据全市场交易日历定位 T+1 与 T+2。停牌或上市前的空缺不可被当成成交机会。
- 166 只股票中 147 只从 2023-01-03 起有数据，其余 19 只后上市或历史较短，最短 127 行。样本最低前复权收盘价为 1.24 元，没有低于 0.05 元的价格。
- `688693.SH` 在 2026-03-16 返回 0 成交量及 0 成交额、重复前日价格，疑似停牌占位行；已跳过该单行，其余历史保留。异常明细见 `manifest.json`。
- 粗筛发现约 341 个开盘较前一有效收盘上涨至少 9.5% 且开盘接近最高价的观测。该筛选不是精确涨停判断；按主板、创业板、科创板、北交所和特殊股票分别计算涨跌幅限制，开盘封板不可简单视为可买入。

## 生产前仍需解决的偏差

当前股票列表不是历史时点股票池。已退市股票及当前 `ST` 股票被排除，会产生幸存者和状态选择偏差。AKTools 本地接口 `stock_info_sh_delist` 与 `stock_info_sz_delist` 分别可提供沪市、深市退市清单（本次检查分别返回 159 与 208 行）；下一轮应把 2023 至 2026 年当时仍上市的退市股票纳入历史股票池，并逐日使用上市、退市和历史 `ST` 状态过滤。两表含 B 股，需按代码筛选 A 股。当前样本未据此扩展，不能代表生产级无偏覆盖。

前复权价格会随未来公司行动重算。若把整个历史期一次性前复权后的技术指标视作当日实际已知数，可能出现时点偏差；正式验证应采用当日可得的复权因子快照或不复权价格与当日公司行动记录。成交模拟还需独立核验停牌、涨停开盘、滑点、费用及买卖价格。
